## Irregularities and blockers

1. **No organizer authentication:** the official data page is login-walled. The public bridge reassembly script is deliberately labelled an owner-mirror fallback, not an official downloader.
2. **Sample raster inconsistency:** local sample finite values equal `labels.tif`; the official problem page describes the sample as predicting no faults. The sample is only a georeferencing/footprint template in all code.
3. **Feature nodata inside the scoring footprint:** the local preparation receipt counts 3,061 float32 sentinel cells in each of the six selected feature bands even though labels/template call those cells valid. The loader masks them and derivative transforms nearest-fill from valid neighbours; the influence of these pixels has not been separately evaluated.
4. **Invalidated buffer pass:** the first local experiment varied a buffer around catalogue labels. It was invalidated after the staff exact-mask ruling, and no file from that pass was exported. The corrected exact-pixel-mask result is the only current candidate; see the [design log](design-of-experiments.md#organizer-clarification-changed-the-initial-plan).
5. **Score attribution:** 0.2778 is a verified public-board score for `extradr19` in this snapshot, but “H33 = 0.2778” remains unlinked and unverified.
6. **Target mismatch:** local spatial holdouts measure transfer to withheld existing mapped faults, whereas hidden competition labels are newly captured fault pixels. No conversion factor or leaderboard lift is claimed.
7. **External data pending:** the official USGS conductance files are available in principle, but resolution, coverage, reprojection and utility must be audited before H35-04 is implemented.
