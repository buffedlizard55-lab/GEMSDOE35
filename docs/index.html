The 0.2778 question

Plausible to beat; unverified to attribute.

What is verified: on the 2026-10-04 public-board snapshot, 0.2778 is shown for `extradr19` at rank 13; the leader is 0.3262. No organizer record links that row to H33. The owner’s H33 PR #9 describes a removal/pruning arm and a projected local 0.2747, explicitly not an organizer score. In principle, removing low-credit pixels can help if avoided false-positive cost exceeds lost true-positive credit, but that does not explain or attribute the public 0.2778. This project does not copy the near-catalogue buffer rule; staff say only known pixels are masked exactly and nearby predictions are scored normally. Neither this public row nor our local proxy establishes private or final-round performance.
